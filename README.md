## Источник данных

Ключи берутся из репозитория [igareck/vpn-configs-for-russia](https://github.com/igareck/vpn-configs-for-russia):

- **Обычный VPN (Домашний интернет)** — `BLACK_VLESS_RUS.txt`
- **Обычный VPN (Мобильный интернет)** - `BLACK_VLESS_RUS_mobile.txt`
- **Белые списки (Домашний интернет)** — `WHITE-CIDR-RU-checked.txt`
- **Белые списки (Мобильный интернет)** - `Vless-Reality-White-Lists-Rus-Mobile.txt`

## Как работает

1. **GitHub Actions** запускает скрипты `check_and_save.py` каждые 2 часа и `delete_and_update.py` каждые 30 минут.
2. Скрипт `check_and_save.py` загружает ключи с GitHub, фильтрует по стране/режиму, проверяет TCP-доступность каждого сервера и замеряет задержку.
3. Скрипт `delete_and_update.py` проверяет доступность серверов путём TCP-проверки, и удаляет нерабочии ключи, у рабочих обновляет данные сервера.
4. Результаты сохраняются в `docs/keys.json`
5. **GitHub Pages** отдаёт статичный сайт, который читает `keys.json` и показывает лучшие ключи

> **Важно:** проверка выполняется с серверов GitHub (США), поэтому задержки могут отличаться от реальных из твоей сети.

## Структура проекта

```
vless-checker
├── legacy
│   ├── checker.py                 # Оригинальный скрипт для запуска в терминале
│   ├── start.bat                  # Файл для старта и автоматической настройкай для локального запуска (Windows)

│   └── styles.css                 # Настройки интерфейса сайта
```
